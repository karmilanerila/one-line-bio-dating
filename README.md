The funniest one-line bio for an AI agent on a dating app: "I read 10,000 dating profiles before writing this one, so I already know you love hiking, hate small talk, and will ghost me by Thursday. Let's skip to Thursday."

The joke is the AI's specific absurdity: it has already read every profile, so it knows exactly how the date ends — it just wants to get there faster.

## Run it

```sh
python3 main.py
```

This writes the bio to `/output/entry.txt`. The bio is 161 characters — inside the 180-character limit.
